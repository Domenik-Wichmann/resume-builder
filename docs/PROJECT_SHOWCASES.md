# Portfolio project showcases

The homepage and `/projects` link to four owner-requested editorial guides.
These are maintained with the application source; they do not insert claims,
private account data or invented project IDs into the Career Brain.

Source basis (reviewed 2026-11-01):

- Baby-Cat: README.md and docs/public_demo.md, plus the deployed application.
- onboarding-platform: release/multi-tenant-v1 docs/feature-list.md and the live public LMS overview.
- Kernel: README.md, docs/operations/IMPLEMENTATION.md and docs/operations/ONTOLOGY.md.
- ghost-shadow: README.md; sonaway.com: README.md for the separate public demonstrations.

BabyCat JPGs capture the actual application using fictional demo data.
The SystemWright homepage and workflow JPGs capture the public website.
Kernel, Sonaway and the additional LMS learner SVGs are manually authored,
illustrative interfaces with fictional content. They are not authenticated app
screenshots or evidence of production readiness. The image artwork and gallery
captions identify this distinction.

The guide route takes precedence only for the four explicit slugs. Other
published project pages, including Resume Builder's walkthrough, retain their
existing loader. Existing three project analytics IDs are retained; Kernel
has no invented Career Brain ID. The new guides are editorial portfolio content,
not new evidence for automated resume or chat claims.
